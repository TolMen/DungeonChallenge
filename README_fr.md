## 📖 Présentation  

**DungeonChallenge** est un jeu de console en **Java** où le joueur incarne un aventurier explorant un donjon mystérieux rempli de gardiens et de défis.  
L’objectif est de collecter un maximum de pièces d'or tout en prenant les bonnes décisions pour avancer.  
Chaque choix influence votre progression et peut mener à la victoire… ou à l’échec !  

## 🎲 Comment jouer ?  

1. **Lancement du jeu** : Après l’exécution du programme, suivez les instructions affichées.  
2. **Exploration** : Faites des choix stratégiques pour progresser dans le donjon.  
3. **Défis et combats** : Affrontez des gardiens, évitez les pièges et récupérez des trésors.  
4. **Victoire** : Ressortez du donjon avec le plus de richesses possible ! 🏆✨  

## 🚀 Installation  

### Prérequis  
- **Java JDK 8+** : Assurez-vous d’avoir Java installé sur votre machine.  
- **IDE ou Terminal** : Le jeu peut être exécuté dans un IDE (NetBeans, IntelliJ, Eclipse) ou directement via un terminal.  

### Étapes d’installation  

1. **Cloner le dépôt**  
   ```sh
   git clone https://github.com/TolMen/DungeonChallenge.git
   ```  
   OU  
   ```sh
   git clone git@github.com:TolMen/DungeonChallenge.git
   ```  

2. **Compiler le projet**  
   Dans un terminal, accédez au dossier du projet et compilez le code :  
   ```sh
   javac DungeonChallenge/DungeonChallenge.java
   ```  

3. **Exécuter le jeu**  
   Une fois la compilation terminée, lancez le jeu avec :  
   ```sh
   java DungeonChallenge.DungeonChallenge
   ```
